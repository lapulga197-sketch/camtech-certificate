# ស្ទូឌីយោឯកសារ (Certificate Studio)

ប្រព័ន្ធដាច់ដោយឡែក (database + Vercel ផ្ទាល់ខ្លួន) សម្រាប់រចនា និងបោះពុម្ព៖
សញ្ញាបត្រ · ប័ណ្ណសរសើរ · លិខិតសរសើរ · លិខិតជូនពរ · កាតសិស្ស (មុខ/ក្រោយ, ព្រីនច្រើនកាតលើ A4)។

- អ្នកប្រើចុះឈ្មោះដោយខ្លួនឯង → **ត្រូវរង់ចាំអេដមីនអនុម័ត** ទើបអាចចូលបាន (`/admin/users`)
- គំរូ (templates) រក្សាទុកតាមអ្នកប្រើ — អេដមីនអាច «ចែករំលែក» គំរូទៅអ្នកផ្សេង
- តារាង database បង្កើតស្វ័យប្រវត្តិនៅពេលប្រើលើកដំបូង — **មិនបាច់ run command ណាមួយទេ**

## របៀប Deploy (ធ្វើក្នុង browser ទាំងអស់)

1. **Neon** (neon.tech) → New Project (ថ្មី ដាច់ពីប្រព័ន្ធដើម) → ចម្លង *Connection string* (ជម្រើស Pooled)។
2. **Vercel** → Add New → Project → ជ្រើស GitHub repo ហើយជ្រើស branch `certificate-studio`
   (Settings → Git → Production Branch = `certificate-studio`)។ Framework = Next.js។
3. Vercel → Settings → Environment Variables ដាក់៖

| Name | តម្លៃ |
|------|-------|
| `DATABASE_URL` | connection string ពី Neon |
| `AUTH_SECRET` | អក្សរចៃដន្យវែងៗ (≥ 32 តួ) |
| `ADMIN_EMAIL` | អ៊ីមែលអេដមីនដំបូង |
| `ADMIN_PASSWORD` | លេខសម្ងាត់អេដមីនដំបូង (≥ 6 តួ) |
| `NEXTAUTH_URL` | អាសយដ្ឋានគេហទំព័រ ឧ. `https://xxx.vercel.app` (សម្រាប់ QR ផ្ទៀងផ្ទាត់) |

4. Deploy → បើកគេហទំព័រ → ចូលដោយ `ADMIN_EMAIL` / `ADMIN_PASSWORD`។
5. អ្នកផ្សេងចុះឈ្មោះនៅ `/register` → អេដមីនចូល **អ្នកប្រើប្រាស់** → ចុច «អនុម័ត»។

> បើមិនដាក់ `ADMIN_EMAIL` គណនីដំបូងគេដែលចុះឈ្មោះនឹងក្លាយជាអេដមីនធំស្វ័យប្រវត្តិ។

## មុខងារគ្រប់គ្រង (អេដមីន)

មីនុយ **គ្រប់គ្រង** (ខាងលើ) មាន៖
- **អ្នកប្រើប្រាស់**៖ អនុម័ត/បដិសេធ/ផ្អាក, កំណត់លេខសម្ងាត់ថ្មី (មានស្លាក «ស្នើប្តូរលេខសម្ងាត់» ពេលអ្នកប្រើចុច «ភ្លេចលេខសម្ងាត់»)
- **ស្ថិតិ**៖ អ្នកប្រើសរុប/ថ្ងៃ/ខែ, ការ run មុខងារ, device, ទីតាំង, IP (ទីតាំងបង្ហាញពេលដាក់លើ Vercel)
- **ស៊ុម / ម៉ូតឯកសារ**៖ អាបឡុតស៊ុម PNG/SVG ឲ្យ user ជ្រើសក្នុងស្ទូឌីយោ
- **ការកំណត់ប្រព័ន្ធ**៖ ឈ្មោះ app, favicon, icon, logo, ផ្ទាំងស្វាគមន៍ (អក្សរ + រូប/QR), អំពីយើង, ទំនាក់ទំនង, ឯកសារណែនាំ PDF
- ប៊ូតុង **រូបរាង** (ក្បាលទំព័រ)៖ ភ្លឺ / ងងឹត / ដូចប្រព័ន្ធចាស់ + ពណ៌ប៊ូតុង + ពណ៌ផ្ទៃ

## ការស្រោចស្រង់លេខសម្ងាត់តាមអ៊ីមែល (ជម្រើស)

ដាក់ `MAIL_FROM` ជាមួយ `RESEND_API_KEY` ឬ `BREVO_API_KEY` ក្នុង Vercel (មើល `.env.example`)។ បើមិនដាក់ទេ ប្រព័ន្ធនៅតែដំណើរការ — អេដមីនទទួលសញ្ញា ហើយកំណត់លេខសម្ងាត់ថ្មីជូន។

## សុវត្ថិភាព

- ចាក់សោគណនី ១៥ នាទី បន្ទាប់ពីខុសលេខសម្ងាត់ ៦ដង; កំណត់ចំនួនសំណើតាម IP (ចូល/ចុះឈ្មោះ/ភ្លេចលេខសម្ងាត់/ផ្ទៀងផ្ទាត់/នាំចូល Excel)
- ទម្រង់ចុះឈ្មោះមាន honeypot + សញ្ញាសម្គាល់ពេលវេលា (ទប់ bot); តំណកំណត់លេខសម្ងាត់ប្រើបានម្តង ១ ម៉ោង
- លេខសម្ងាត់ hash ដោយ scrypt (មិនរារាំង server); header សុវត្ថិភាព + CSP; ឯកសារអាបឡុតត្រួតពិនិត្យប្រភេទពិតប្រាកដ (មិនទទួល SVG ដែលមានកូដ)
- ចុះបញ្ជី QR រាប់រយឯកសារ ប្រើ query តែបួន — ហើយ QR បង្កើតនៅ browser អ្នកប្រើ មិនធ្ងន់ server
- សូមប្រើ connection string **pooled** របស់ Neon (មាន `-pooler` ក្នុងឈ្មោះ host)
